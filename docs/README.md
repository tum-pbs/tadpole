# Tadpole project page

A buildless static project page for **Tadpole: Autoencoders as Foundation Models for 3D PDEs with Online Learning**.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Push these files to the repository branch you want to publish.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the branch and the `/ (root)` folder.

No build step is required.
